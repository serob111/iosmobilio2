# Дизайн Mobilio (Vivid)

Источник — холст Mobilio в Claude Design. Эта папка — его выгрузка для вёрстки в `apps/web`.

## Что здесь лежит

| Путь | Что это |
|---|---|
| `screens/*.png` | Скриншоты каждого экрана в исходной ширине (1440 — десктоп, 390 — телефон, 640 — письма). Это **визуальный эталон**. |
| `source/*.dc.html` | Исходники экранов: точные цвета, размеры, отступы, тексты, состояния. Брать значения отсюда, а не «на глаз» со скриншотов. |
| `source/canvas.json` | Список экранов холста с размерами. |
| `tokens.css` | Токены дизайн-системы для Tailwind v4 (`@theme`) + шкала типографики в комментарии. |

## Как читать `.dc.html`

Это HTML с инлайн-стилями и простым шаблонизатором. Сам шаблонизатор переносить не нужно — верстать на React/Next.js + Tailwind.

- `{{ path }}` — значение из `renderVals()` в `<script type="text/x-dc">` внизу файла.
- `<sc-if value="{{ cond }}">` — условный блок (разные состояния экрана: пустое, загрузка, ошибка, успех).
- `<sc-for list="{{ items }}" as="item">` — список. Примеры данных — в `renderVals()`.
- `onClick="{{ fn }}"` — обработчик; что он делает, видно в классе `Component`.
- `data-props` — переключатели вариантов экрана (например, `empty` у «My apps», `outcome` у письма о ревью). Каждый вариант — отдельное состояние, которое нужно сверстать.
- `<helmet>` — стили и шрифты страницы (анимации, hover).

Скриншоты показывают **начальное состояние** экрана. Остальные состояния (`sc-if`) — в исходнике.

## Правила

- Язык макетов — английский. Все строки — через next-intl, en и ru обязательно (русский перевод делать живым языком, не дословно).
- Данные в макетах (Lumen, Anna, цены, даты) — примеры. На реальных экранах — данные из API.
- Квадратные скобки (`[YOUR DOMAIN]`, `[COMPANY LEGAL NAME]`, `[EXPIRY DATE]`, `[SPOTS LEFT]`) — заглушки. В коде — из конфигурации/env/API; в прод-сборку текст в скобках попадать не должен (тест на это).
- Цены тарифов — из одного места (константы планов), не разбросаны по вёрстке.
- Вёрстка резиновая: десктоп 1440, телефон 390, без горизонтального скролла от 320px.
- Доступность: семантические теги, `label` у полей, видимый фокус, контраст AA, `aria-*` как в исходниках, анимации выключаются при `prefers-reduced-motion`.
- Одна лаймовая кнопка на экран и только на тёмном (`ink`) фоне.
